# ADK + AG-UI + A2UI v1.0 demo

A small *reference-based integration demo*, **not** the official A2UI v1 React reference renderer.

- **Official backend adapter:** `ag-ui-adk` + `ADKAgent` + `add_adk_fastapi_endpoint`.
- **Official frontend AG-UI client:** `@ag-ui/client` / `HttpAgent`.
- **A2UI v1.0 surface messages:** `createSurface`, `updateComponents`, `updateDataModel` and `path` data bindings.
- **A2UI renderer:** intentionally minimal demo renderer for a custom accounting catalog (Table/Card/Chart). The official `@a2ui/react` renderer currently lists v1.0 as *planned*, so do not confuse this with a reference implementation.
- **Behavior:** ADK chooses component with `show_ui` tool. The frontend converts its arguments deterministically into A2UI v1 surface messages. Thus the *LLM does not compose A2UI messages directly*; that is a future enhancement.
- Mock endpoint uses the same AG-UI wire events so the demo works without Google credentials.

## Run

Python 3.11+ and Node 20+.

Terminal 1 (offline mock; drop `DEMO_MODE=mock` and set `GOOGLE_API_KEY` for Gemini):

```bash
uv sync   # installs from the repo-root pyproject.toml
DEMO_MODE=mock uv run uvicorn backend.app:app --reload --port 8000
```

Terminal 2:

```bash
cd frontend
npm install
npm run dev
```

Visit http://127.0.0.1:5173. The header shows which mode the backend is in (`Gemini ADK` by default, `Offline mock` with `DEMO_MODE=mock`); there is no toggle in the browser. Try:

- `Vis mine fakturaer` → Table
- `Vis mit KPI-overblik` → Card
- `Vis omsætning som graf` → Chart
- `Hej` → streamed Markdown only

## Gemini mode

Gemini is the default (`DEMO_MODE=adk`). Start the Python server with a key:

```bash
export GOOGLE_API_KEY="your-api-key"
export GOOGLE_GENAI_USE_VERTEXAI=FALSE
DEMO_MODE=adk uv run uvicorn backend.app:app --reload --port 8000
```

The browser follows the backend's `DEMO_MODE` (reported by `/health`). The official `ag-ui-adk` adapter is served at `/agent`. For Vertex AI use ADC and the relevant Google project/location environment variables instead.

## Architecture / limitations

```text
Browser (React)
  @ag-ui/client HttpAgent
      │ HTTP + AG-UI SSE
      ▼
FastAPI
  /mock-agent → standards-shaped mock AG-UI SSE events
  /agent      → official ag-ui-adk adapter → Python ADK → Gemini
      │
      ▼
AG-UI TEXT_MESSAGE_CONTENT → stream Markdown
AG-UI TOOL_CALL_ARGS(show_ui) → convert to A2UI v1 surface messages
      │
      ▼
Minimal A2UI v1 renderer for trusted Table/Card/Chart custom catalog
```

Important limitations:
1. A2UI surfaces are assembled in the browser from `show_ui` args rather than being generated by the LLM or transmitted by AG-UI as native A2UI payload events. This is an intentional demonstration boundary.
2. The custom catalog URL is illustrative and the small renderer is not a fully compliant A2UI runtime; use a maintained v1-capable renderer once one is supported.
3. In-memory ADK sessions and fixed user ID are for local testing only. Production requires authenticated user IDs, durable sessions, access control, redaction, proper tool policies and catalog/schema validation.
4. This demo does not depend on CopilotKit; it uses AG-UI's reference client SDK directly. For the Google-endorsed full integrated UI, scaffold the official CopilotKit ADK project using `npx copilotkit@latest create -f adk`, then wire an A2UI-capable catalog/renderer.
